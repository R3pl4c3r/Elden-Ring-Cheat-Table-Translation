# Elden Ring Cheat Table 中文翻译



艾尔登法环（Elden Ring）Cheat Engine Ultimate Table 中文翻译与更新。



本项目主要针对 **[Elden Ring Ultimate Cheat Engine Table](https://www.nexusmods.com/eldenring/mods/48)** 的最新版本进行中文翻译迁移，旨在将已有中文翻译同步到新版 CT 表，并补充与修正部分遗漏、错误翻译内容。适用游戏版本 v1.17.1



## 项目说明



本项目的主要工作包括：



* 将已有的中文翻译迁移至新版 **Elden Ring Ultimate Cheat Engine Table 8.0.4**

* 参考并继承原有汉化项目中的翻译内容

* 翻译 **褪色者包（Tarnished Pack）** 中的武器、防具、灵马皮肤等内容

* 修复发现的未翻译项目

* 修正部分错误、遗漏或不一致的翻译

* 尽量保持与游戏官方简体中文本地化的术语一致



本项目定位为 **翻译迁移与补全项目**，重点放在 CT 表中文化以及已有汉化成果在新版本中的延续。

## 使用方法



1. 下载 7.5 版 [Cheat Engine](https://web.archive.org/web/20260218073503/https://d2oq4dwfbh6gxl.cloudfront.net/f/CheatEngine/1032/CheatEngine75.exe)

2. 在下载目录打开 cmd/powershell 使用 `./CheatEngine75.exe /VERYSILENT /ZBDIST` 安装 Cheat Engine。务必确保按所发布的方式使用该命令，因为不使用额外参数会导致 Cheat Engine 的安装程序触发其恶意软件行为。

如果你不小心错误地运行了它，并且注意到了异常情况，请删除以下文件：
```
autorun/eatme.lua
autorun/soundextension.lua
autorun/dlls/dnd.dat
```
3. 禁用 EasyAntiCheat

   - 创建 `steam_appid.txt`，内容为 `1245620`
   - 找到你的 Elden Ring 文件夹（例如 `C:\Program Files\Steam\steamapps\common\ELDEN RING\Game` 或 `~/.steam/steam/steamapps/common/ELDEN RING/Game/`）
   - 将 `steam_appid.txt` 移动到与 Elden Ring 可执行文件（`eldenring.exe`）相同的文件夹中
   - 通过 `eldenring.exe` 运行游戏


4. 下载本项目提供的中文 CT 表

5. 使用 Cheat Engine 打开 CT 文件

6. 启动《艾尔登法环》

7. 将 Cheat Engine 连接到游戏进程

8. 按照 CT 表中的功能说明使用对应功能



建议在使用修改功能前备份游戏存档。



## 注意事项



Cheat Engine 以及本 CT 表能够直接修改游戏运行状态。使用过程中可能造成存档异常、游戏崩溃或其他不可预期的问题，请自行承担使用风险。



使用在线模式前请确认相关功能的风险。建议在离线环境中使用修改功能。



本项目属于 **翻译/汉化工作**，不负责维护 Cheat Engine 本身，也不负责维护原版 CT 表中的功能逻辑。
